# Figure provenance

`endurance_test.png` is a historical visualization generated from the old port-based parser. Its labels describe port 4443 as hybrid TLS and call parser-accepted TCP flows completed handshakes; neither interpretation is verified by the raw packet text. It is retained for provenance only and is superseded by `docs/evidence/endurance_packet_audit/audit_report.md`. Do not use it as a quantitative or protocol-validation figure in a submission.
